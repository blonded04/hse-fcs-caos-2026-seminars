# Общее
Цель занятия: потренироваться с указателями, как они используются в Си.

Разрешается изменять только код, помеченный `TODO`.
Запрещается добавлять шаблоны.
Корректное решение должно компилироваться в отладочном режиме (с ассёртами),
выводить `OK` ровно один раз и не ронять санитайзеры.

Весь нужный синтаксис и идеи должны были быть на лекции или в этих упражнениях.

# Синтаксис (`0x`)
## `01-compile`
Скомпилируйте программу на языке Си из двух единиц трансляции.
Для компиляции и линковки используйте команды `gcc`/`clang` вместо `g++`/`clang++`.
В `CMakeLists.txt` достаточно правильно указать расширение файла: `.c` вместо `.cpp`.

Теперь запустите и с санитайзером, и под Valgrind — должна найтись утечка памяти.

## `02-struct`
Данный код на Си не компилируется (но скомпилировался бы на C++),
потому что на Си структуры называются не так, как в C++, нужно слово `struct`.
Исправьте код, сохранив определение структуры.

## `03-malloc`
Создайте динамический массив из `n` интов на языке Си.
Вместо `new`/`delete` используйте `malloc`/`free`.

## `04-qsort-int`
Разберитесь, как можно вызвать функцию `qsort` для сортировки массива `int`'ов.
Вам требуется понять два параметра этой функции и как правильно написать `int_comp`.

То же самое можно было бы написать и на C++, но в C++ у нас есть шаблоны и `std::sort`.

# Для домашки (`1x`)

## `12-realloc`
Уже почти реализована функция `read_line()`, которая читает строчку произвольной длины
и возвращает владеющий указатель `char*` на неё.
Допишите недостающий кусок, занимающийся расширением буфера.

Сохраните линейную сложность работы.
Если память закончилась (то есть функция выделения памяти вернула `NULL`), то `read_line` тоже должна вернуть `NULL`.
Память не должна утекать ни при обычной работе (проверьте санитайзером), ни если функция вернула `NULL`.
